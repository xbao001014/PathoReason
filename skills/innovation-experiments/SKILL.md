# 创新实验管理

从用户已选候选及其证据开始；若只有模糊方向，使用 [baseline-innovation](../baseline-innovation/SKILL.md) 补齐关键假设。延续已有授权，先完成可审阅的准备，再处理真正需要用户决定的分岔。复用 [task-code-workspaces](../task-code-workspaces/SKILL.md) 与 [training-execution](../training-execution/SKILL.md)，不另建执行通道。

## 准备有判别力的矩阵

- 读取真实 task_id、候选版本、基线源码/环境快照、数据划分、特征、验证选择规则和已有尝试。用可靠的既有基线结果作为参照；协议不一致或重复不足时说明为什么需要匹配的对照运行。既不机械重训全部基线，也不禁止必要的对照与多种子验证。
- 将候选变成一项最小机制改动及必要的消融/替代解释对照。预先约定主指标、机制读数、可接受成本、提前终止规则和判定标准；记录改变项及固定项。组合多个改动前先能区分各自贡献。
- 可提出分阶段实验：低成本判别 → 有证据的候选完整比较。写清每阶段的单元、进入条件和预计成本；只有实际准备并被批准的单元可执行。后续阶段不自动继承未批准的额度或范围，不把已批准完整矩阵偷偷缩成单种子试跑。
- 训练/验证承担开发选择；最终评估按冻结协议。曾曝光的测试保留非独立、非盲法标识及累计暴露；不能由新划分、新任务或新实验清零。

## 内部适配与一次审阅

适配已有方法、改变预测/损失链路或编制成本时，先读 [方法核验与成本依据](references/method-and-cost.md)。形状、有限梯度和概率和为 1 不能证明方法忠实；新增机制进入真实训练前由 Agent 自行核验。核验与修订属于内部准备，不增加用户逐项确认。

1. 在 Agent 所有的任务代码仓库中修改实现，保留父任务/基线来源；注册新修订、检查并冻结，旧快照不改。不要修改公共平台来迁就某个研究结论。
2. 可在现有许可内执行纯合成、无真实数据的 CPU 接口/形状检查，明确它只验证工程行为。任何真实数据试训，包括“一轮 smoke test”，都纳入公共训练计划与预算，不走裸 bash、独立后台进程或 compute_exec 绕过执行器。
3. 冻结环境、绑定受控输入和输出依赖，准备具体计划。主基线训练完成不等于批准新创新实验。分别列出 Agent 回合/时间余量、训练累计墙钟/GPU 秒、单元超时及尝试数；未知值保持未知，估算不充当授权或消耗。
4. 训练进度栏已有同范围有效批准时按回执继续；新方案/预算需要用户决策时，使用现有 Training 栏一次审阅，checkpoint needs_input 后结束当前回合。不要另造重复的 Guidance 确认、冻结确认或“再说继续”。预算不足只报告可选缩小范围或追加预算，数值由用户决定。

## 执行、诊断与修复

当前公共控制器按实验串行运行 CPU 或所选单个 GPU，worker 禁止 fork/exec/network。数据加载采用兼容的线程或零子进程方式；不要照搬“占满所有 GPU”、多进程加载或子 Agent 并发训练。

启动后按 training-execution 使用 `waiting` 与真实 `training_run` 回执让目标引擎等待；不在模型回合内循环轮询。恢复后先 inspect 原运行，未知派发不能重放。利用实际 epoch、日志时间戳、验证曲线和预算判断进展；没有上报的遥测不视为零或卡死。

运行慢先定位 I/O、计算或记录瓶颈，再提出有证据的优化。精度、batch size、早停等会改变优化轨迹，须作为显式方案变化处理；不能以“性能优化”为由静默改变科学比较。

失败区分工程错误、数值异常、机制不支持和证据不足。能在已批准范围修复的工程问题，由研究 Agent 修改自身任务代码并在同实验登记修订、保留原尝试和消耗后重试。重试仍服从当前尝试/预算及用户控制状态；停止、暂停、耗尽或未知状态不自动重启。科学假设没有获支持不等于执行器坏了；记录负结果、替代解释和下一项有价值的验证，预算或价值不支持时允许搁置，不无限“救活”候选。

## 形成下一节点

真实回执到达后使用 [innovation-checkpoint](../innovation-checkpoint/SKILL.md)，发布带方案/代码/运行/原始产物引用的结果及失败历史。按冻结指标汇总全部约定种子/折的比较和波动，缺失单元明确列出；保留当前最好且可比的基线/候选，不拿单次最高分替换。

区分：工程可运行、原生集成、模型自主完成、科学证据支持。进程完成不等于创新有效；指标提升不自动证明机制、独立泛化或科学审核通过。负结果也可完成一次有价值的判别实验。
