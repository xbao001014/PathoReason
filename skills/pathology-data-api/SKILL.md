# 病理接口数据接入

先读取当前项目已有输入、回执和用户授权，明确要获取的病种、诊断状态、染色范围与交付物。用户已经明确授权的同一范围继续执行；不要仅因跨了模型回合再次索取批准。训练、付费生图及超出既定范围的拉取另按对应预算处理。

## 选择协议与执行路径

- 当前服务 ai.gzfxyl.cn 的接口 2.0 使用 X-AiData-Key、PageIndex/PageSize；先读 [接口与关联规则](references/api-v2.md)。旧截图中的 Limit 协议及 study_io.py data 不能代替此分页协议。
- 不在提示词中读取含真实密钥的整份接口说明。使用下述 helper 在进程内读取凭据；只把无密钥的接口规范加载进上下文。
- 列出本次需要的端点及范围。完整数据集必须说明哪些端点已覆盖、哪些不适用或未授权；不能把一个成功 GET、完整患者列表或 PageSize=1000 称为全部信息。
- 从疾病字典确认精确身份，再取病种相关主列表。按唯一患者查询富集；可生成一个批量查询计划，由一个脚本执行分页循环，避免每一页或每个患者都占一个模型步骤。

可复用 helper（仅负责传输与来源，不计算研究结论）：

```bash
/home/bxn/projects/PathoReason/.venv/bin/python \
  /home/bxn/projects/PathoReason/skills/pathology-data-api/scripts/fetch_pages.py \
  --project PROJECT_ID --plan plans/data-queries-v1.json --output inputs/source-vNEW
```

计划示例和续跑语义见 [helper 使用](references/fetch-helper.md)。开始前先核对已有回执，避免重取已完成数据。输出采用新版本目录；同计划续跑仅接受校验通过的完整查询。中断的查询保留现场，先检查回执；不自动重发未知结果。完成一批后读取 summary.json 和 complete.json，而非仅看进程退出码。

## 分页与来源判定

每页保存响应原字节、HTTP/API 状态、查询参数、SHA256、大小和采集时间；认证头不进入回执。只有保存成功且 API 返回有效数据才推进分页。遇到满页继续下一页；遇到有效末页才标记查询完成。达到本地页数或时间上限时写明 incomplete，不能伪装成空页或完成。

原始响应与合并数组分开保存并分别计算 SHA；响应摘要不能用于验证重新序列化的数组。每个完成清单绑定原查询及全部分页文件。历史源字节缺失应记录证据不足，不通过重新计算摘要补造来源。

## 关联与统计口径

- 同时报告记录行数、唯一患者数、唯一标本数、唯一切片/WSI 数。多记录患者分布在去重前计算。亚型的患者数按唯一 PatientId 计算，多个标签可能重叠；不能默认互斥。
- 病人级富集可能返回该患者其他病种。亚型、属性先按病种身份过滤；分子结果按患者和标本联合关联。无法建立同标本映射时标为待核验，不把患者标签自动赋给全部切片。
- HE 与非 HE 的特征覆盖分开统计。保留空值、冲突、定量单位、来源和原始标签。标准化/去重规则另存，不覆盖输入；不擅自挑一个冲突标签。
- 文件存在、路径引用次数、唯一文件数、张量读取成功是不同证据。特征抽样不能证明全量训练可用。需要读片时核对实际解释器；服务器 PathoReason .venv 的 FXio 与旧引擎 Python 的依赖可能不同。

## 面向图件的接口匹配

若任务涉及论文图表、组织图或热点图，读取 [接口与图件能力匹配](../../.agents/skills/pathology-mil-paper-figures/references/api-capability-matching.md)。分别记录接口字段/引用、实际文件及空间证据、已注册提供器和当前图件缺口；统计图、真实组织图与概念示意图使用对应路径。接口返回路径为空或只有特征时，保留缺失记录，不推断组织像素或 patch 坐标。

## 收尾与后续回合

由当前研究 Agent 自己生成、核验和登记用户所需结果。开发调试发现错误应改进通用能力并反馈证据，不能把开发者代改的研究报告当模型验收成功。

在项目 plans/ 保存本轮范围/默认过滤，inputs/ 保存来源，outputs/ 保存模型生成的汇总与适用性判断。用 study_io.py publish 登记用户要求的成果，并区分回合结束、采集完成、数据可训练、科学审核通过。

为核验和成果登记留出步骤。接近回合上限时保存已完成查询、未完成项和下一步位置；接续时读这些文件，不重放采集。不要因缺失可选标签或某类文件而中止全部已授权工作；指出该缺口影响的具体研究用途。
