# 对话历史节点导航

2026-11-02 前端增量发布，后端保持 `0.6.13-p5-goals`。入口位于对话消息区域左侧，独立于项目空间和研究目标进度。

- 桌面以回合为节点，当前阅读位置高亮；单个自动接续回合使用短刻度。按可用高度聚合过密节点，悬停/聚焦展示相邻回合，点击具体条目定位原消息。
- 概览使用原用户消息、已有回复的有界文本摘录、真实回合状态和时间，不新增模型调用或保存另一份模型总结。长标题/回复省略显示，点击后可阅读原文。
- 窄屏使用历史按钮打开可搜索列表，避免压缩正文。支持键盘上下/Home/End 导航、右箭头进入概览、Escape 关闭并返回焦点。
- 查阅旧消息时，轮询、自动接续及流式更新不再强制跳到底部；点击“返回最新”恢复跟随。新进入会话默认定位最新；原工作台“来源回合”定位仍使用同一个跳转入口。目标处短暂高亮。
- 页面只读导航，不改变会话、目标、权限、预算、研究数据或 Agent 输出；删除/空会话不显示节点。新增回合在下一次现有会话刷新时进入导航。

实现：`ConversationHistory.tsx` / `conversation-history.css`，App 中替换原无条件自动滚动。当前服务器 API 本来就返回整个会话，本次不引入历史分页/虚拟列表；大量完整消息的渲染仍受原页面性能约束。

## 验证与发布

TypeScript/Vite 构建通过。浏览器以原会话只读请求检查真实内容悬停、跳转、轮询后位置保持及 1440/390/320 三宽度；以显式浏览器夹具覆盖 100+ 回合聚合、键盘进出、历史查看时新增回合、最新位置流式增长及窄屏搜索跳转。无浏览器异常、无 API 写请求、无模型推理调用。工具验证不宣称新增任何科研能力。
