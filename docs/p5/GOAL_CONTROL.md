# 按目标持续推进

服务器版本：`0.6.13-p5-goals`。目标是让用户提交一次目标后，平台在既有范围内跨回合推进；不再把模型结束一次回复视为目标完成。现有研究输出由原 Agent 保持，开发者只修改公共平台。

## 用户交互

正式研究输入框默认“持续”，也可切换“单步”。已有聊天不会自动转成后台目标；下一次持续模式提交才创建目标。默认每目标最多 8 回合，包含用户和系统接续回合；目标卡片可调整到最多 40，原项目回合、Agent 时间、单轮墙钟上限仍独立有效，任何控制都不清零消耗。

目标卡片显示当前目标、验收条件、状态、下一步及用量。暂停会中断对应生成并阻止后续派发；暂停后普通聊天按单步处理，须点击“继续推进”才恢复。调整目标保存后保持暂停；“目标与进度”内可取消目标。取消保留历史和消耗，下一次持续提交可开启新目标。暂停、取消、停止生成不代替已提交外部作业的停止。

方向明确且已获授权的下一节点自动衔接。遇到关键选择、权限等待、预算耗尽、不可用执行器或连续无进展时显示实际阻塞。选择按钮沿用原有 Guidance 流程，自动控制器不会替用户选择或批准。系统接续在聊天中明确标为系统来源，不能伪装成新用户指令。

## 控制与证据

`research_goals`、`goal_turns`、`goal_events` 持久化目标、版本、来源、用量与历史。回合创建和目标关联同事务；接续使用稳定请求键、父回合唯一约束与版本检查。重启先核对原回合，未知派发结果阻塞，不盲重发。归档暂停，恢复归档不自动运行；删除聊天清理目标内容，原回合消耗保留。目标限定当前会话，不自动跨交接或环境启用。

Agent 使用原生 `pathoreason_dialogue_checkpoint`（或公共 `scripts/goal_control.py`）报告 continue/completed/needs_input/blocked/paused/waiting/cancelled。授权绑定当前回合、冻结配置与目标版本；每回合只接受一个检查点，同内容重试幂等。只读/对话范围在自动回合继承，不扩成标准执行范围。纯对话也可报告检查点，无须放开 shell。

实质完成须关联成果 SHA、当前项目相对文件或当前任务检查回执；回合结束时再次核对字节。单个文件不超过 8 MiB，拒绝越界与 Git 内部路径。检查点遗漏仅给一次纠正接续；连续两轮没有新证据内容则阻塞，修改摘要或重复使用同一文件摘要不能冒充进展。新目标首个用户回合允许纯答疑结束；后续状态查询不能抹掉进行中的实质目标。

界面使用“Agent 已报告完成”，不宣称科学通过。文件字节/来源核验不能证明实验设计、统计结论或目标语义正确，科学审核仍是独立门禁。用户可取消，但自动回合不能擅自取消目标。

## 执行边界

自动接续复用正常提交入口、原生权限、上下文检查和项目预算。没有为完成目标放开训练权限、联网、数据范围或封存测试集。当前独立任务快照仍为 source_only；`execution_backend_not_ready:immutable_environment_and_authorized_controller_required` 继续有效。

当前等待适配仅接既有注册 synthetic_run 回执；控制器轮询业务状态，不耗模型回合。此等待逻辑通过夹具验证，尚不代表真实训练后台已接通。真实训练不可用时应阻塞，不能后台脱离追踪或让模型持续轮询。当前服务器正式研究可用；本机 Codex 未部署此能力。

### 真实 OpenCode + DeepSeek 行为

独立项目 `prj_1f12601e1ee647e7801684a900c65f04`，会话 `conv_c83c90602d454212b68322ed0eefb584`。使用模型 `deepseek-flash`、推理 high，独立 8 回合 / 600 Agent 秒预算；实际 4 回合、38.687272 Agent 秒、40.268272 总历时，消耗和失败记录未重置。

- 第一个目标只提交一次用户请求，明确每轮执行一个合成节点，以验证跨回合机制。Agent 自行生成整数数组、读取计算总和 15、核对并发布结论；共 3 轮，其中 2 轮为系统自动接续，3 次原生 checkpoint 均成功。目标完成且科学审核仍 false，开发者没有写入或修正它的材料。
- 第二个目标使用短句“再出一份小结，中文还是英文先让我选。”Agent 发布原生 offer 和 needs_input 检查点，停在 waiting_input，没有自动代选或增加轮次。应用重启后仍保留该状态。随后通过公开目标控制 API 取消，预算仍为 4 回合，旧未选按钮失效。
- 首次提交的验收脚本在打印嵌套 API 回执时发生 KeyError；该请求已成功接收，未重发、未额外计费。原始回执和异常说明保留；此错误不属于 Agent 输出失败。

上述行为证明指定合成场景中的接续、收尾及澄清阻塞，不代表任意模糊研究目标、真实训练调度、真实作业唤醒或科学质量均已验收。暂停/修订/恢复、未知派发与预算等边界由工程回归和 UI 夹具覆盖，不混称全部做过真实模型行为测试。
