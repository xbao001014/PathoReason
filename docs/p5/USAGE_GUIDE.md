# 指南与工具（2026-11-04）

左侧“工具”改为“指南与工具”，保留 tools 导航存储键。原有卡片以 Skill 名称、迁移状态与流程分组为中心，不能说明如何开始或处理阻塞；新版先给任务说明，再连接当前项目的实际控制入口。

## 实现

- 快速开始、研究流程、常用操作、问题恢复共 21 条说明。研究流程沿用平台五阶段，支持关键词与能力名称搜索；步骤、输入、产出、示例和支撑能力按需展开。
- 顶部结合项目归档/清理、连接、目标与稿件状态提供相关入口。阶段、目标、训练只在打开指南或手动刷新时读取；请求取消与会话 key 防止过时回写，不增加后台轮询。
- 原能力清单继续由 API 提供，动态保留未列入静态说明的新能力；研究能力、合成验证、未接入场景分别折叠。接入与验证证据分开标注，选用限制沿用 skillOptions。浏览、搜索与展开不切换执行模式。
- 示例追加到原草稿，保留既有能力选择并提示核对；显式“选用并填写任务”才更换能力。不会自动发送、创建项目/对话、调整预算或批准审核。合成入口必须在独立普通项目、已选择合成模式且实际能力可用时选用。
- 操作连接现有工作台、项目/对话维护、上下文、连接、额度、模型、权限、显卡与状态模块。状态模块跳转等待组件加载，支持打开折叠面板与选择相应页签；切换页面/对话取消等待。不存在的模块显示原因；运行时变化或读取异常仍由原入口限制，定位超时给出反馈。
- 指南 JS/CSS 单独按需加载；正文 14px、辅助信息 12px，统一语义色与圆角，桌面双列输入/产出，窄屏单列。
