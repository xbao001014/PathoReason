# 数据查询模块（2026-11-06）

版本：0.6.43-p5-data-browser。入口：左侧固定导航的「数据查询」，位于研究工作台之后。

## 使用与实现

- 保留原导航、项目空间和主内容三列。四类业务查询组织 10 个已公开端点；疾病搜索先查字典，再选定编码。参数按端点显示；患者富集须指定患者，文本追溯须患者或病种。
- 预览有表格、字段选择、详情弹窗、原始记录 JSON、患者关联查询、字段非空计数、分页和请求条件/时间/响应 SHA。空路径显示未提供，非空路径仅显示有引用/未核验。无接口总数时不编造总量；满页仅表示可能还有下一页。
- 查询预览、图表适配、接口说明使用键盘可达的切换入口。图表匹配基于当前页字段；模型预测、文件实际可读性及科学结论均不由预览推断。
- 后端直接发起只读 GET，不调用研究模型。仅允许固定域名/端点/参数，关闭重定向；单页 1–100 条、响应 2 MiB、网络超时 12 秒、最多 3 个并发请求。聚合不传分页参数，保留显式空诊断条件和 CurrentOnly。未知/失败请求不自动重试。
- 密钥只在服务器进程读取，目录接口只展示是否配置。API 响应 no-store；原始患者记录不写浏览器持久存储、不进入通用仓库或图像服务。沿用当前应用的本机 Host/同源写请求限制。
- 最近查询是进程内最多 16 项、30 分钟预览，服务重启或缓存淘汰后不可再读取。保存快照将当前页原始响应、结构化预览和查询/摘要回执写入当前项目 inputs/data-browser/dq_ID/，不作完整队列声明。
- 项目快照可在重启后读取；读取核对项目身份、文件边界及 SHA。重复保存同一查询幂等，内容变动拒绝覆盖。归档/删除中的项目禁止保存；项目删除沿已有 projects/PROJECT_ID 资产清理规则覆盖快照。列表有界显示，最多 50 项。
- 带入研究对话先保存快照，再追加带相对路径的摘要草稿；不自动发送，不改变原稿件、批准或研究额度。只在可用正式研究对话启用。保存期间离开页面、切换项目/对话或对话变为不可写时，不填入过期草稿。
- 一般项目可保存查询快照；正式研究对话才提供数据 Skill 交接。未选项目可查询，不能保存；归档项目可查看已有快照。

首版不实现 WSI 在线解码、文件扫描、区域标注、批量采集或自动图件生成。现有输入与提供器匹配规则继续适用；本模块提供可审阅的数据来源和具体缺口。

## 代码和契约

- src/pathoreason/data_browser.py：端点/字段目录、有界传输、短期缓存、图表缺口、项目快照。
- src/pathoreason/api.py：/api/v2/data-browser 下的 catalog、query、recent、queries/{id}、snapshots 及项目快照读取。
- apps/web/src/DataBrowser.tsx、dataBrowser.css：独立按需加载页面；复用 ComposerSelect 和状态语义色，App 保留现有功能。
- 新契约快照 contracts/api-p5-data-browser.openapi.json、contracts/p5-data-browser/；前端类型由脚本生成。历史契约未覆盖。
- 页面只有显式操作才请求上游数据；目录/历史/快照读取不触发上游拉取，也不新增后台轮询。
