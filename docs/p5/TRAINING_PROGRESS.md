# 研究工作台实时实验进度

2026-11-03，版本 `0.6.23-p5-training-progress`。用户要求实时矩阵、训练/评估完成数、epoch、损失/验证曲线、日志与失败重试历史、独立训练预算消耗；沿用既有授权，不中断或重启当前训练。

## 数据与界面

- 工作台概览显示真实已登记实验摘要，实验运行页显示矩阵、独立预算、单元/尝试选择、曲线、日志和全部尝试历史。历史材料、报告矩阵和科学审核标识保留，报告条目不计为正式单元完成。
- `GET /api/v2/research-projects/{pid}/training-progress` 从 SQLite 只读事务取得实验、尝试和最近 30 条事件；不调用 `Training.view/reconcile`，不初始化表、不写账本、不发送控制指令。
- `GET .../training-progress/{eid}/attempts/{aid}` 读取同项目、同实验下指定尝试的任务指标和日志。数据按尝试隔离，不拼接失败/修复前后的曲线；单元完成按当前 scope 的 completed 回执去重，与执行器跳过已完成单元的语义一致。已用预算包括全部失败和修复尝试，运行中时间来自原单调时钟和已观察值；没有重置预算。
- 页面每 4 秒读取，隐藏页面暂停轮询；请求不重叠，15 秒超时。更新失败保留最后记录及时间、明确显示更新中断；跨实验/尝试切换丢弃过期响应。未上报指标显示未知/尚未上报，不推算 epoch 或伪造曲线。当前 epoch 表述为“当前单元已上报 epoch”，不能当作正在计算的 epoch。
- 继续/停止/授权/预算调整仍回到原对话的可折叠进度栏；工作台没有直接控制训练的写接口。

## 通用指标与读取边界

兼容既有 `epoch-N.json`、`metrics.json` 的 `rows`/`history`、`progress.json`、`metrics.jsonl`。每条记录含非负数字 epoch；读取有限训练/验证损失及常用评价指标，忽略非有限值、样本级字段和其他未知字段。训练/验证曲线可切换已上报指标，原值可展开查看。任务需自行输出指标；公共机制不改任务源码，也不反向填写研究结果。

读取目录从账本 run_id/unit_id 推导并与 output 身份比较；逐级 O_NOFOLLOW 打开目录和文件，拒绝符号链接、越界路径及 FIFO/设备等特殊文件。目录最多扫描 10000 项、逐 epoch 文件最多取最近 512 个、单文件 16 KiB；汇总/JSONL 最多 1 MiB。曲线最多返回最近 512 个有效 epoch，worker.log 最多读取末尾 64 KiB，截断与无效/正在写入文件有说明。所有新接口只支持 GET，项目/实验/尝试身份逐层校验，Cache-Control 为 private, no-store。日志按文本渲染。

注册任务选择仅展示该任务的实验；历史展示分组下明确显示“项目已登记实验”，不猜测历史文件与执行回执的绑定。实验完成不等于科学审核通过；当前 previously_exposed 范围持续显示非独立、非盲法。冻结快照、环境和原运行身份可展开核对。

契约新增到 `contracts/p5-training-progress/` 与 `api-p5-training-progress.openapi.json`，旧契约保留；由 `scripts/export_training_progress.py` 再生成。

## 验证与发布

证据目录：`/data/bxn/PathoReason/acceptance/live-training-progress-20261103/`。

- 工程：24 项只读进度与历史工作台回归通过，覆盖当前 scope 完成数、失败累计消耗、不触发 reconcile、尝试/项目隔离、部分 JSON、非有限值、符号链接/FIFO/路径拒绝、读取上限和 GET-only。TypeScript/Vite 构建通过。已有 Starlette 测试客户端弃用提示保留。
- 浏览器：真实训练只读预览在 1440/390/320 三宽度核验矩阵 30 单元、两类完成数、独立预算、两个 30 点曲线、历史失败日志及科学边界；布局截图留存。另用浏览器 GET 夹具验证自动刷新、网络失败保留旧值/恢复、阶段筛选、空实验仍保留历史报告。所有非 GET 请求均拦截，没有模型或真实训练调用。
- 发布：仅新增只读接口及前端展示。训练执行器、冻结 controller kit、任务脚本、预算授权不改；应用可在 Agent 空闲时重载，独立训练控制进程与 OpenCode 不重启。发布前后 run_id/controller PID/start identity、活动尝试和消耗分别留证；运行中的训练数据自然增长不能要求全库字节不变。
- 本次证明的是展示接口、浏览器交互及对真实运行数据的只读接入，不新增模型修复能力或科学审核通过结论。

回退使用发布前源码/静态备份，只恢复应用代码和静态 index/assets，必要时在 Agent 空闲时重载应用。不得恢复旧数据库或消费账本，不停止/重放训练。发布后的实际 commit、进程连续性与浏览器结果见 release.json 和 browser-deployed.json。
