# 会话归档与删除

发布：`0.6.4-p5-conversations`。服务器 8520；本次仅更新应用，OpenCode 8522 和独立研究进程不随应用重启。

## 前端操作

项目空间每条会话右侧 `⋯` 打开管理弹窗。

- **归档会话**：默认列表隐藏；“显示已归档”可查看并恢复。聊天、原生上下文、草稿保留；归档期间不接受新回合、压缩或权限配置变更。
- **删除… → 永久删除**：确认后清除在线聊天与会话上下文。成功后移出列表；删除最后一个会话后可通过“新建对话”继续。
- **清理未完成 → 重试清理**：原生删除或本地清理失败时显示真实状态；停止读取该会话和发送消息。刷新页面或应用重启后仍可核对、继续清理。

活动回合、未决派发、原生工具确认、原生执行和未决压缩会阻止归档/删除。操作前应完成或停止并核对。删除不代表停止独立科研任务。

## 清理范围

清除应用数据库中的聊天正文、输入、工具摘要、事件、上下文快照及投影、Skill 调用上下文、运行时绑定和会话权限配置。交接回执清除自由文本，保留来源映射和摘要，避免丢失成果来源或重放历史。保留压缩计数；研究回合保留 ID、状态、时间、用量、配置摘要和成果关联，原有回合/墙钟预算不会回退。

绑定 OpenCode 的会话通过原生 `DELETE /session/{id}` 清除，并用 `GET /session/{id}` 返回 404 确认。先核对原生目录、共享引用和派生会话；共享或有派生会话时拒绝级联删除。若删除已发生但回执丢失，重试先查询存在性。已有本机 Codex 绑定暂不支持原生删除，返回 `native_deletion_unsupported`，可归档；本次没有部署本机 8530。

**项目资产保留**：同项目的会话共用 `projects/PROJECT_ID`。数据集、模型创建的项目文件（包括自行写入的 memory.md 等）、研究任务、输出、已发布成果、研究来源以及冻结的科研配置均属于项目资产，不因删除单个会话而删除。当前版本没有登记为会话独占的单独记忆文件；不得猜测文件归属后递归删除目录。

浏览器删除对应草稿、引用选择和模型设置；同源其他标签页通过 storage 通知更新，其他浏览器通过轮询核对。已复制/导出的 handoff、下载文件、备份和引擎外部日志不在此功能的清理范围。SQLite 清理是在线逻辑删除，不承诺磁盘取证级擦除。保留的研究成果可能包含会话衍生内容。

## 接口与恢复

- `GET /api/v1/research-projects/{pid}/conversations?include_archived=true`：包含归档及清理未完成的会话，不返回已删除会话。
- `POST /api/v1/conversations/{cid}/archive`、`/restore`。
- `DELETE /api/v1/conversations/{cid}`，JSON `{"confirm":true}`。
- `GET /api/v1/conversations/{cid}/lifecycle`：可读取删除状态回执。
- `POST /api/v1/conversations/{cid}/deletion/reconcile`，JSON `{"confirm":true}`：显式继续清理；不会重新发起模型请求。

`conversation_deletions` 是增量旁表。状态为 deleting → deleted 或 failed；进程中断保留 deleting。已删除会话的历史、回合上下文、交接导出及提交返回 410；未完成清理返回 409。原生删除完成与本地清理分别持久化，本地清理在单个 SQLite 事务内执行。新提交和删除共享服务锁，并在持久化新回合的事务内再次检查生命周期。

新契约快照为 `contracts/api-p5-conversations.openapi.json` 和 `contracts/p5-conversations/`，保留原有快照。不得用旧数据库备份恢复已删除聊天；出现发布问题应前向修复，并保留删除回执。
