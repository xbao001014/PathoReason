# 阶段浮层的信息层级与折叠布局

2026-11-04。用户指出模块和元素排列缺少主次、折叠简陋，展开内容与后文间距过小。此补发仅修改前端结构与样式，沿用 0.6.31 的阶段交接/作者审核 API 和动作语义。

当前审核节点采用 16px 主标题，步数单独对齐，辅助说明 12px。需要用户确认的信息及实际阻塞优先显示，其后是材料列表与表单；长摘要移至“本轮审核说明”。五节点流程折叠为次级模块，避免未开始节点持续占据审核首屏。新建阶段会话的主操作与当前审核有独立分隔。

新增共用 StageDisclosure，保留原生 details/summary 的键盘行为，采用整行点击、SVG 旋转箭头、数量元信息、浅底展开标题、分隔线与独立内容区。展开正文顶留白 20px，底部 20px/窄屏16px；模块间至少16px。箭头在有无数量时均对齐，窄屏元信息移到标题下方；不裁切长标题。遵循 reduced-motion。

交接正文按摘要、已确认决定、局限与审核边界、待解决问题、下一步分组，组间20–24px、标题与正文12px；审核历史、返工与研究五阶段采用同一折叠组件。保留原稿引用、原文、确认与返工控件、禁用条件、CAS/幂等提交和只读边界。阶段历史初稿标题明确为历史交接，不误称新窗口接收。

浮层宽度520px并受标题容器宽度约束，采用统一卡片留白28px/24px，内部滚动；正文14px，元数据12px，状态颜色沿用公共 tokens。标题行入口保持原来连接状态的轻量风格。
