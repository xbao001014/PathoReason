# 五阶段研究流程与显式会话交接

目标版本：0.6.28-p5-stage-handoff；2026-11-04。

## 产品约定

顺序固定为数据准备 → 基线方案确定与基线实验 → 创新方案确认与创新实验 → 结果分析与科学审核 → 稿件部分。阶段内部沿用既有目标自动接续、权限、澄清和训练预算机制；不新增逐步冻结/合成验收确认。完整阶段交付后，对话标题行中右侧显示阶段入口与显式提醒，折叠后提醒与“切换并继续”仍可见。点击该按钮或在待切换状态输入“继续”“下一阶段”等短语，进入同项目的新会话；不会等到上下文满才分阶段。第五阶段显示最终交付完成，不创建空的第六阶段。

切换动作确认进入下一环节准备、分析与交付，不批准新训练、额外封存测试评估或对外发布。正结果不是推进条件；负结果与不确定性必须进入交接。阶段交付与科学审核、作者确认分别记录。

## 实现与上下文

- 新正式项目自动从 data 初始化；旧项目通过 stage API 明确关联当前阶段，前几个环节不据此倒填完成。
- 公共 checkpoint 增加可选 stage_handoff：当前阶段、工作流修订号、摘要、已确认决定、至少一项局限、待解决问题、下一步和训练 run 引用。普通子任务 completed 不代表阶段完成。Agent 使用当前阶段相关原生 Skill；声明发现不等于实际调用。
- 只有成功结束的回合、合法目标授权和已核验文件/成果才能生成交接。训练阶段要有公共执行器已完成的尝试引用；运行中/结果未知的训练会阻止交接。失败和原始输出不删除。
- 交接保存来源会话/回合/目标、配置摘要、带哈希的成果引用、训练方案/环境/快照/评估范围/独立预算、上游阶段证据，以及有来源标记的 Agent 摘要。摘要是主张，不是新的权限或科学结论。
- 切换核对工作流/目标修订、证据摘要与文件实际版本、原生空闲和待处理权限。目标原 ID、回合消耗和上限不变；项目及独立训练账本不变。复制当前会话的有效权限和显卡设置，新的 native session 在后续派发时建立。
- 源会话保留，可查看历史、跳转新会话。转移事务与源会话/修订幂等，重复点击不创建重复会话。旧页面发起过期切换会被拒绝。继续修改原阶段会撤销旧的待切换状态，但保留交接历史。
- 同阶段上下文恢复仅重绑会话，不推进阶段；已接收的阶段交接随之保留。用户仍需人工决策的节点沿用原澄清与科学门禁。

存储：research_workflows / research_stage_events / research_stage_transfers，追加事件、保留历史。API：GET/POST `/api/v2/conversations/{cid}/stage`、POST `.../stage/switch`。契约为 contracts/p5-stage-handoff 与 api-p5-stage-handoff.openapi.json。

## 分层验证

工程：完整回归 504 通过 / 3 跳过；最终相关模块 44 通过；检查点回执措辞补齐后 7 项阶段测试再次通过。独立 CPU 合成训练 + 模拟模型五回合测试覆盖五阶段、显式等待、负结果、同一目标/额度、同阶段上下文恢复、证据变化和并发运行门禁。不是研究训练验收。

浏览器：真实构建，隔离写请求的夹具在 1440/390/320px 验证五阶段、待切换提醒、键盘展开/折叠、折叠后仍可操作、局限展示、旧修订冲突、重复点击、正确新会话与接收上下文；自由输入“继续”走同一切换接口，未派发真实研究回合。构建通过；原有大包提示保留。两次初始键盘夹具失败是 CDP 缺少 Enter 字符事件，补齐真实按键参数后通过，原始日志保留。

原生：上线时刷新空闲实例并核对实际 MCP checkpoint schema 与 Skill 正文；最终结果以 acceptance/stage-handoff-20261104/release.json 为准。刷新不重启 OpenCode，不终止训练。

模型行为：开发期间旧 H1 流程自行完成原授权实验及结果/稿件交付，目标达到 completed，10/11 回合。这是旧流程结果，不是新五阶段模型验收。新协议待后续真实 Agent 使用；工程/原生通过不能冒称模型五阶段已验证。

科学：阶段交接永远不写科学批准；现有非独立、非盲法限制及稿件非投稿就绪标记保留。本次不修改研究 Agent 的脚本、结果或报告，不增额度、不启动训练。

## 标题行展示调整（2026-11-04）

按用户要求，将阶段入口移至对话标题右侧、连接状态左侧，移除输入框上方的阶段卡片。点击入口向下展开阶段列表和交接内容，不推挤对话与输入区域；待切换时保留直接可见的“切换并继续”。窄屏在标题区域内换行，长阶段名称省略但可展开查看，保持可见阶段编号；浮层受视口宽高约束。Escape 收起并返回入口焦点，点击外部收起；原关联选择菜单仍可操作。

仅前端展示改动，沿用原 stage API、授权与目标控制。构建、三宽度夹具与真实数据只读浏览器验证，覆盖标题位置、输入区无位移、浮层边界、键盘/外部收起、旧修订拒绝、重复点击与自然语言切换。证据位于 acceptance/stage-header-20261104；静态发布不重启服务、模型或训练，不新增模型/科学验收。
