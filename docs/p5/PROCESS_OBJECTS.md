## 实现

新增可选 ToolSummary.targets、target_count、operation、working_directory 及 ToolTarget；旧记录默认空集合继续兼容。`tool_objects.py` 仅从固定结构化字段与字面命令／顶层 Python 文件操作提取路径、脚本、Skill、网页、文件匹配范围和实验 ID；已知训练 operation 提供具体动作名称。没有执行被解析的命令或代码，不导出原始参数、内容、输出、grant 或内部推理；网页省略用户信息、query 和 fragment。动态路径、未知操作或无法判断的代码保持原简要摘要。

时间线的动作下方显示对象短名；点击或 Enter 展开完整原生工具名、操作、工作目录与对象路径。多目标数量可见，最多展示 12 项并说明余数。对象、操作或工作目录不同不合并，即使旧重复键相同；训练调用和失败继续单列。`已返回` 和其他状态语义不变。

契约快照为 `contracts/api-p5-process-objects.openapi.json` 和 `contracts/p5-process-objects/`，旧快照保留。类型生成同步纳入当前已有的训练进度类型，不修改其运行逻辑。
