# PathoReason 使用说明

1. 连接已获授权的 Tailscale 网络，在浏览器打开 http://100.84.214.106:8520/ 。
2. 左侧选择“胃间叶源性肿瘤探索实验”。进入“研究工作台”查看当前项目成果，可预览和下载正文、PDF、图件及源码包。
3. 切回“执行操作台”查看研究对话。已有归档对话位于“已归档”，历史审核、实验及预算记录随案例保留。
4. “数据查询”支持接口预览、关联查询及图表适配信息。保存查询快照后可追加到当前对话草稿；发送前可以修改草稿。
5. 开展新任务时通过项目空间的“+”新建项目，设置任务与额度；训练执行和稿件审核使用界面的对应确认入口。

地址由同一台服务器持续提供，版本更新由维护者统一发布。遇到无法访问时，先确认 Tailscale 已连接且账号有该服务器的访问权限，再联系维护者；不要将地址改为服务器的公网入口。
