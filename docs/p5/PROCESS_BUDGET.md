# 执行过程与 Agent 计时

版本：0.6.11-p5-process-budget，2026-11-01。由最近一轮十次 bash 全部显示“命令”的反馈形成公共层修复，不改研究 Agent 的脚本、数据或结果。

## 行为

- 工具摘要按实际 shell 结构分类：读取、检索、数据准备、配置、依赖、训练入口、日志、等待、成果登记等。组合命令保留多类动作。仅输出固定标签，不公开命令、路径、参数、输出或模型推理；不能识别的动作保留通用标签。标签表示入口类型，不证明命令内部行为或科学成功。
- 仅连续、已完成且命令完全相同的读取/检索/日志/状态/等待可折叠，展开保留每次调用及其耗时。训练、依赖及组合命令逐条展示；旧记录缺少可靠身份时不合并。“命令返回”不等于训练成功。
- 总历时继续显示真实墙钟。新正式回合的 Agent 时间估算为总历时减去有原生时间戳证据的工具区间并集；并行区间不重复扣除。工具包含执行和有时间记录的等待。缺失时间戳、连接中断后未观察到的区间不推定免费；恢复后可依据原生完整记录核对。
- 不是模型供应商计费，也不是 GPU 训练计时。现有项目后续新回合采用新口径；历史扣账保留，不回填或退款。项目摘要同时展示预算计时、总历时、已排除工具时间及历史口径说明。旧 max_wall_seconds 字段兼容保留，含义为混合口径的预算秒数。
- 维持回合数和原生步数限制；每个新正式回合另冻结 max_turn_wall_seconds（默认 86400 秒，API 可设 60–604800）。停止生成及预算中止不保证终止外部训练。训练预算、科学门禁与 GPU 设置独立。

## 持久化与历史展示

turn_timing 仅在创建新口径回合时写入，保存工具区间并在断线/重启后延续；删除对话仍保留预算证据。回合配置冻结 time_accounting 和单回合墙钟上限。无计时账本的旧回合按原墙钟计算。

历史工具展示可通过 `scripts/refresh_process.py --turn <id>` 从对应 OpenCode 会话和消息只读获取工具元数据，生成 turn_process_projection 旁表。仅适用于终态回合，工具 ID/名称须完整匹配；源摘要不匹配则拒绝或回退原展示。此操作不调用模型、不执行研究命令，不改原 turns 文本、工具、用量或预算。删除对话会清除展示投影。
