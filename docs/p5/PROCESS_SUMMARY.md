# 回合执行过程摘要与折叠

服务器应用版本 `0.6.5-p5-process`。每轮回答上方显示独立的执行过程条，替代原来的平铺工具标签和固定“正在核对证据”文案。

## 展示行为

- 正在处理时显示真实阶段（模型处理中／等待工具执行／当前工具动作／正在输出回答）和工具调用次数。耗时为整个应用回合墙钟时间，包含等待，不等于模型纯思考时间；工具次数不等于 Agent steps 或预算回合数。
- 新回合在输出前可展开；开始公开文字输出时自动折叠，回合结束时再次折叠。用户在输出期间手动展开后，后续文字增量不会反复收起；历史回合和页面重载默认折叠。
- 展开区域最多 240px，超出后内部滚动。连续相同摘要的已完成调用合并；失败项逐条保留，折叠条仍显示失败次数。
- 工具状态显示“调用完成”，不据此认定数据核验、研究完成或科学审核通过。回合结束后仍 pending/running 的调用显示结果未确认。
- Skill 调用不再全部误标“结果解读”。后续回合可显示白名单中已识别的 Skill 名称；历史缺失名称的调用只显示“加载 Skill”。

## 数据与边界

原生适配器仅输出确定性工具动作摘要、状态、原生已报告的 duration_ms 和 activity_phase。摘要不复制原始命令、参数、工具输出或内部推理文本，不增加模型请求；未知工具用通用名称，不猜测读取接口、校验成功等业务结果。原回答正文原样保存与显示。

元数据沿用现有 turns.tools 和 turns.usage 持久化；不迁移、不回填旧研究记录。ToolSummary 新增可选 summary、duration_ms，Usage 新增可选 activity_phase。没有工具原生时间时不伪造耗时。删除会话沿用原清理规则，清除工具过程详情；归档保留。

契约新快照 `contracts/api-p5-process.openapi.json`、`contracts/p5-process/`；原会话生命周期等历史快照保留。本机 Codex 的已有工具记录使用同一前端兼容展示，本次仅部署服务器，未部署或验证本机推理。
