# 工作台当前成果展示

2026-11-04，版本 `0.6.40-p5-workbench-outcomes`。

## 问题与结果

工作台默认选中了最后一个历史方案文件系列，即使项目已经完成稿件作者审核，也仍停留在创新方案。后续报告缺少旧分类器识别的 Schema，阶段交接和稿件审核包没有进入关联投影。

现在有平台阶段记录的项目默认进入“当前项目成果”，以平台当前节点为准；早期任务仍可切换查看。总览突出当前正文、PDF、源包、阶段结论与待处理事项；分析与验证集中显示结果/对照报告和关联图件；稿件与图件按当前审核包显示，历史审核包、旧稿和核验材料默认折叠。正文、图片、PDF 可在工作台预览，反馈和审批返回原对话。

本次只修改公共展示与读取机制，没有改研究稿件、图件、实验、作者批准、额度或模型提示。没有新增模型调用或科学审核。

## 来源与状态规则

- 一次只读数据库事务读取产物、可见会话、阶段工作流和稿件工作流；不调用会初始化状态的 workflow get/owner。
- 阶段交接的核验引用、稿件包的确切 artifact ID/SHA 优先于 Agent 关联清单；共享材料原归属保持，项目总览为非排他的汇总视图。
- 老材料按明确字段、Schema、文件目录及报告用途补充导航分类。路径归类标注为导航依据，不生成执行、科学或作者批准。仍无法归类的材料保留在全项目材料中。
- 当前稿件使用 pending 或有效 approved 节点，不按文件版本号排序冒充当前批准；撤销的旧批准只保留在历史。正在准备、待作者审核、作者已批准有独立展示。
- 结论优先采用分析阶段交接，再采用最近交接／当前稿件请求中的摘要字段；显示来源原文，不自动翻译、改写研究结论或从患者数据生成新结论。
- 项目聚合阶段计数是关联文件数，包含保留的历史；专门稿件区只突出当前审核版本。无平台阶段记录的旧项目保留原默认行为。
- 原稿按注册文件核验读取；审核材料使用不可变审核快照。缺失、跨项目、SHA 不符和已删除来源会话不能生成审核预览链接；归档会话仍可读。后续会话迁移不阻断原审核快照读取。

新增只读接口：`GET /api/v2/research-projects/{pid}/research-workbench/reviews/{review_id}/materials/{artifact_id}`，支持 `download=true`；无对应写操作。响应禁缓存、禁 MIME 嗅探，文本始终纯文本并保留 sandbox。PDF 验证文件签名，用 `default-src 'none'; object-src 'self'; frame-ancestors 'self'` 支持同源原生阅读器；不把 PDF 放在禁插件的通用 sandbox 中。
