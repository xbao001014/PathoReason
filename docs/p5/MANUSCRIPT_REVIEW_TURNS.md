# 稿件审核后的回合窗口

2026-11-04，版本 `0.6.37-p5-review-turns`。用户要求稿件各环节提交审核反馈后重置回合计数。本次修改公共目标与审核机制；没有代替作者作出审核决定，也没有发起实验或修改项目额度。

## 行为

有效的 approve、revise、clarify、reopen 与作者回执在同一事务保存目标 `turn_window`，以当前累计 `turns_used` 为起点。目标上限 `max_turns` 约束累计用量减去窗口起点，沿用用户原设置。确认节点后，下一节点从零计数；要求修改或补充后，当前节点从零计数。最终交付确认后的成果登记也有独立窗口。已完成或取消的目标不恢复。

`turns_used` 保留目标全程累计用量。项目总回合、Agent 时间、训练预算和科学门禁保持原约束；审核反馈不能绕过项目额度。暂停目标记录反馈与窗口，但保持暂停，待用户明确恢复。重置同时更新额度版本，防止旧额度表单跨窗口覆盖。

重复 request_key 重放原回执，不再次重置；过期版本、无效或被门禁拒绝的反馈不重置。Agent checkpoint、重新上传审核材料、普通聊天和刷新页面均不重置。上下文恢复与应用重启保留窗口。旧目标无窗口时继续按累计计数，下一次有效作者反馈才开始新窗口；没有数据库批量迁移或追溯重置。

界面在窗口启用后显示“本节点 x / n 回合”，任务详情显示目标累计用量；额度表单按窗口实际消耗设置下限，明确项目消耗不清零。API 增加可选 `turn_window`，历史目标兼容，快照在 `contracts/p5-review-turns/`。
