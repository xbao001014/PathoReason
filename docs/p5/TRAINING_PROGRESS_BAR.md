# 训练确认并入对话进度栏

2026-11-03，用户要求训练方案/预算确认放在输入框上方已有的可折叠栏。替代先前输入框工具栏的“训练”按钮与模态弹窗；后端训练授权、CAS、预算和停止/恢复协议未变。

- 同一进度栏显示目标状态和当前实验状态；待确认时显示“待确认训练方案”。整行可点击，支持原生按钮键盘操作及 aria-expanded/aria-controls。
- 展开后直接审阅方案、实验矩阵与评估范围、编辑独立训练预算及执行动作。矩阵明细折叠，预算和启动后果明确保留；没有实验时不显示空训练表单，没有目标但已有实验时仍可使用。
- 收起/展开、正常状态轮询保留未提交的预算。目标异步加载或执行阶段换目标不强行收起表单。其他窗口改变方案/预算修订时保留本地输入、禁用旧提交，用户载入最新方案后重新核对。
- 桌面内容最大 42dvh/480px，窄屏最大 25dvh/240px，在栏内滚动；输入框保持可见。停止生成和停止训练的语义未变。

仅前端交互工程和线上只读检查；不新增原生引擎、模型行为、GPU 训练或科学验收结论。真实草案仍未批准，提议预算未生效；不修改 Agent 已用额度或研究产物。
