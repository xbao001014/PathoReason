# 对话框设置入口简化

2026-11-02，按用户确认的预览实施。纯前端增量，应用仍为 0.6.12-p5-workbench。

## 行为

模型、思考、模式、权限、显卡五个入口统一为 18px 线性图标 + 14px 短标签。当前选项保留在悬停/键盘聚焦提示、读屏描述及原菜单/弹窗中。表单内部的下拉框仍显示实际值与箭头，选择、保存、禁用与会话作用域语义保持。

窄屏换行时为发送/停止按钮预留独立位置，320px 下仍能将设置入口排成两列，避免重叠。通用样式与图标在 ComposerSetting.tsx / composer-settings.css；ComposerSelect 以可选 triggerLabel 启用简短触发器。界面规范同步更新于 design.md。
