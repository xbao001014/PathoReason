# 对话框设置入口简化

2026-11-02，按用户确认的预览实施。纯前端增量，应用仍为 0.6.12-p5-workbench。

## 行为

模型、思考、模式、权限、显卡五个入口统一为 18px 线性图标 + 14px 短标签。当前选项保留在悬停/键盘聚焦提示、读屏描述及原菜单/弹窗中。表单内部的下拉框仍显示实际值与箭头，选择、保存、禁用与会话作用域语义保持。

窄屏换行时为发送/停止按钮预留独立位置，320px 下仍能将设置入口排成两列，避免重叠。通用样式与图标在 ComposerSetting.tsx / composer-settings.css；ComposerSelect 以可选 triggerLabel 启用简短触发器。界面规范同步更新于 design.md。

## 验证与发布

TypeScript 与 Vite 构建通过。候选和线上浏览器检查覆盖 1440、390、320 宽度：五个入口与当前值、图标/字号、悬停/键盘提示、三个选择菜单的键盘打开和 Esc 返回、选中项、权限弹窗及内嵌表单、显卡信息弹窗、发送/停止按钮占位。所有检查只读访问真实 API，禁止 POST/PUT 等写请求，无研究对话、计算或设置变更。

证据与原版本备份：`/data/bxn/PathoReason/acceptance/composer-settings-20261102/`。候选构建先独立验证，再发布新增的哈希静态资源，最后原子替换 index.html；保留旧资源以支持已打开的页面。无需重启应用或 OpenCode，无数据库/API/研究产物修改。页面刷新后加载新版本。
