# 悬停闪烁修复（2026-10-30）

用户反馈创建过程中移动鼠标经过按钮／菜单时闪烁。改动仅涉及前端，不启动模型、训练或创建研究项目，不重启应用／原生引擎。

## 发现与范围

实际现有短菜单和创建弹窗在无头 Chromium 中没有复现整页闪烁或弹窗位置振荡。可滚动菜单浏览器夹具（本地拦截模型目录，15 个条目，不修改服务器目录）复现了确定的问题：鼠标移到部分可见选项会触发与键盘共用的 scrollIntoView，在 1440、800、390px 宽度下分别自动滚动 30、30、26px，容易产生选项跳动。

另发现 dialog::backdrop 使用全屏 blur(3px)。改为保留原遮罩颜色的静态遮罩，消除弹窗悬停时的实时背景采样路径；这是针对浏览器合成闪烁的缓解，不宣称已复现用户设备上的 GPU 渲染问题。

## 改动

ComposerSelect 的鼠标悬停只更新活动项，开启及键盘操作才揭示选项，并仅滚动菜单自身。忽略菜单内部滚动引起的重新定位；几何不变时复用位置状态，监听触发按钮尺寸变化。保留键盘方向键、Home/End、Enter、Esc、点击选择及原有权限语义。

## 验证与发布

TypeScript 检查和 Vite 构建通过。1440×800、800×600、390×700 三种布局中，修复后悬停引起的滚动为 0，键盘首尾导航及选择通过，创建表单在连续按钮悬停后位置稳定、内容保留、无横向溢出；无页面错误或 POST 请求。源码修改前核对摘要，独立输出构建，保留旧 assets 后原子替换 dist/index.html，无需重启服务。旧 0.6.0-p5-entry 发布清单保持原样，此修复的摘要单独记录。
