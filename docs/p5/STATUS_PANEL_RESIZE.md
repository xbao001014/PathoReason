# 输入框上方状态面板拉伸

2026-11-04，纯前端静态补发。沿用现有稿件审核、任务/训练分类及折叠结构。

展开后在面板顶边显示横向拖动柄，向上拖动增高，向下拖动缩小。鼠标与触屏通过 pointer capture 连续跟踪，拖离面板也可调节；取消拖动恢复开始时的高度。双击或键盘 Enter 恢复默认。拖动柄可键盘聚焦，方向键以 24px 微调，Shift+方向键以 64px 调整，Home/End 到可用下限/上限；拖动中的 Escape 仅取消调整，普通 Escape 仍沿用稿件面板折叠。

高度保存在当前浏览器本地，桌面/窄屏分别记忆；折叠、切换模块和重新打开保持，审核意见及目标草稿不因调整丢失。默认仍按内容和原视口比例限制高度，用户调节后设定明确高度。上限随实际对话区域、输入框高度和 visualViewport 变化收缩，桌面保留最多 64px、窄屏 32px 的历史区域；窗口变大后恢复用户偏好。极窄/短窗口以输入框可用为先，不能越过当前可用空间继续拉高。

ResizeObserver 和 requestAnimationFrame 合并测量；拖动仅刷新独立手柄与容器高度，不让整个审核/训练模块随每次指针移动重绘。没有服务端写请求、模型调用、预算调整或任务状态变更。

## 验证

- TypeScript/Vite 构建通过。
- 训练及稿件两种模式，1440/1024/390/320px 共八组浏览器夹具：鼠标/真实触摸事件、键盘微调和上下限、模块/折叠切换、草稿保留、刷新记忆、窗口缩小限制与恢复、默认重置、Escape 取消、输入框保持可见及无横向溢出通过。
- 手机空间紧张时最初给历史区预留过多空间，改为独立窄屏预留。320px 布局默认高度已到可用上限时，向上拖动应保持上限；测试据此检查实际边界，而非强制增高并挤出输入框。
- 真实研究页面仅 GET 读取，1440/390px 拉伸及折叠记忆检查；不提交审核、意见、目标或对话。
- 保留同期主线的稿件审核回合窗口更新，未覆盖 GoalPanel 原有额度展示。
