## 已交付

- 独立 React 操作台：左侧 7 个平铺 Skill、项目/会话，右侧聊天；可新建项目和对话、保存草稿、选择已配置模型、引用成果、停止回合。研究工作台与对话随时切换。
- 独立 FastAPI 服务、SQLite WAL 和持久事件序号。请求以 conversation + request_key 去重；每回合保存模型描述、完整运行配置（凭据占位符）、Skill 版本/摘要、项目上下文和输入成果身份。
- OpenCode 1.18.33 HTTP 适配，原生 session 绑定与独立 XDG 存储。异步派发后读取公开回复及工具状态，经 SSE 通知前端刷新回复快照；浏览器重连不发起新回合。应用进程恢复只核对既有原生消息，不重放结果不明的派发。
- 停止保留已收到内容；未知派发回执进入待核对状态；单并发、最多 12 回合和累计 1200 秒初轮验收限制。应用不自动重试模型请求，检测原生 retry 状态后中止；不能将其理解为供应商请求绝对至多一次或硬性费用上限。
- 结果解读 Skill 已接入原生目录，仅允许加载该 Skill；其他业务工具默认拒绝。其余 6 类场景显示待接入，留待 P2。真实推理中的 Skill 加载仍待验收。
- CESC 项目只读绑定 5 份真实成果：结论、稿件索引、PDF、结果图和方法图。图件/PDF/JSON/Markdown 可预览下载并引用到对话。来源读取检查归属、哈希及路径符号链接；生成报告写新数据目录，不写回原成果。
- 工作台显示原冻结模板的 4 个节点和实际状态，明确区分开发复验 60 个单元、完整目标未达成、论文可审阅与尚未投稿就绪。原开发复验与稿件矩阵保留各自来源。
- DeepSeek 凭据检测与重载入口；缺少凭据时发送禁用。文件存在与运行时已加载分开判断。
- Codex 服务器认证接口：状态、设备码登录、取消与失败反馈；不暴露服务器 Codex 推理端点。本机 Codex 真验收仍在 P3。
- 后端 OpenAPI 生成 TypeScript 类型，前端不另维护公共 DTO 副本。原 P0 契约与历史来源快照保留。

## 上下文的当前行为

原生 OpenCode 保存会话历史，自动压缩开启，prune 关闭，预留 20,000 tokens。模型配置声明 1,000,000 context，991,808 input，8,192 output（应用输出上限，不是供应商最大输出）。前端分别展示本轮用量、最近调用的上下文估算和原生压缩记录；不把累计用量显示为窗口占比。

这次验证了配置加载与原生无推理消息跨重启保存。真实多轮、工具调用和自动压缩触发尚未验证；长历史、手动压缩、小窗口切换和本机 Codex 兼容在 P3。P1 仅配置一个模型，选择框不代表多模型验收已通过。PDF/图件可供用户预览，当前模型只获得其索引与身份，未接入二进制解析或视觉输入。
