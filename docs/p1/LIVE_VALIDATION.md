## 真验收发现并修复的问题

1. 普通 user 消息的 `summary.diffs` 被误判为上下文压缩。现仅识别实际 compaction part 或 assistant 的布尔 summary 标志；首轮错误的展示投影已按真实原生消息校正并记录。
2. 原生消息快照的正文可能在结束后才物化，轮询无法保证实时显示。新增 `/event` 消费，支持已核对为 text 类型的 `message.part.delta` 和明确公开文本的 `session.next.text.delta`；不转发 reasoning、工具参数或原始工具输出。最终内容用原生快照对齐。
3. 工具调用步骤结束不再被当作最终回答完成。流式正文未进入快照时，轮询不覆盖已保存内容。
4. 浏览器按短间隔合并消息刷新，仅在完成时刷新成果，避免每个文本片段都重载工作台。
5. 有 SSE 长连接时应用停机可能超过原等待时间；启动器现在等待原 PID 真正退出、排除僵尸进程，应用有明确的优雅停机时限。已用真实生成中的重启验证。

前两次停止检查因未正确消费文本增量而完整生成了回答，检查当时未通过；这些真实回合及报告保留，没有删除失败过程来美化证据。修复后重新验证流式、停止和浏览器显示，最终通过。
