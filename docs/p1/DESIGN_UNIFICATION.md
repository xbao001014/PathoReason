# 统一设计规范与可读性优化

2026-10-30，按用户要求以根目录 `design.md` 作为当前及后续界面修改的统一依据。规范原文保持不变，长期执行要求已写入 AGENTS.md。

## 实现

- `apps/web/src/tokens.css` 集中管理中性色、文字层级、字体栈、字号、间距、圆角与阴影。使用规范中的白色卡片、浅灰画布和侧栏；优先 Geist/Inter 与系统字体回退，不新增外部字体服务。
- 正文、对话与表单提高至 14px；元数据、徽标与辅助标签至少 12px。标题使用 600 字重。取消原有大量 8–11px 文字和 #999/#aaa 等浅灰文字。
- 主文字使用 #0a0a0a / #171717，次级正文 #404040，辅助文字 #626262。保留规范的 #737373 中性色 token，实际辅助文字适度加深，以改善浅灰背景上的可读性。
- 卡片统一 24px，按钮、输入与徽标 18px 圆角；输入边界、选中状态和键盘焦点更清楚。原图件、内容与研究状态值不变。
- `status.ts` / `status.css` 实现规范顶部的优先语义色规则：进行中蓝、完成/检查通过绿、失败/取消/停止红、待处理/待审核琥珀、未开始/未知灰。回合、工具、连接、认证状态、成果预览与业务事实展示共用规则；保留状态文字和图标，不靠颜色单独表达。
- 原有固定窄导航、可折叠项目空间及主内容三列保持。窄屏不缩小正文补偿空间，改用换行与单列卡片。

## 验证

前端 TypeScript 与 Vite 生产构建通过。8 项导航/折叠回归通过；7 项可读性检查通过。对桌面对话、工具上下部分、工作台、报告预览、设置，以及 390px 三个主视图共 9 个页面状态抽样计算 494 个文字节点的前景/背景亮度对比，最低为 5.55:1；无小于 12px 的已采样可见文字。正文另检查为 14px。该结果是本次具体视图的抽样，不代表所有未来内容或全部无障碍要求已认证。

确认完成为绿色、停止为红色，共享五种语义色正确解析；折叠记忆、草稿保留、手机端抽屉和设置入口仍正常，没有横向页面溢出或浏览器 JavaScript 错误。
