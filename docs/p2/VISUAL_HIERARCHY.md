# 当前界面视觉层级调整

2026-10-30，按 design.md 的信息层级规则重新调整现有界面。

- 研究工作台：研究问题、完成进度为主；耗时、矩阵规模为支撑；阶段编号、记录和来源为辅助。验证报告为成果区主操作，图表/指标为次操作，执行账本降低按钮装饰强度。科学审核、独立验证和投稿就绪仍明确保留。
- 待确认方案突出候选参数和确认操作；异常状态突出实际状态和恢复入口。操作仍只填入对话草稿，不直接派发执行。
- 历史项目优先展示完整研究目标，再呈现开发单元、论文与审核状态；数值不再因是数字而一律占据最高视觉权重。事实内容与来源未改变。
- 成果卡片突出文档名称；格式、来源和报告标题中已有的时间拆为次级信息。原成果标题、内容、身份和时间值未改写。
- 工具页保留研究类别与流程层次，能力名称优先于编号、阶段名和可用性标记；待接入能力仍可查看详情，样式降低强调但保持可读。移除重复的类别标题。
- 对话页突出正文和输入操作；正常连接、已完成状态和成功工具记录减少边框装饰，失败/进行中提示保留语义强调。
- 设置页突出服务器主运行时；可选 Codex 登录采用次操作样式，登录接口与功能不变。

复用统一字号、字重、状态色和卡片留白；保留固定导航、项目折叠、共用内容容器及可访问名称。新增视觉角色 token 在 tokens.css，样式规则位于 style.css 的信息层级区段。

验证：TypeScript 检查与 Vite 构建通过；合成/历史项目共 12 种桌面与窄屏布局保持边界、卡片与底部信息对齐，无横向溢出。检查核心指标与元数据字号关系、能力名称与状态层级、报告打开与回引、修订记录、设置页主次及弹窗宽度。待确认/异常的 4 个浏览器模拟场景各保留一个主操作；只覆盖浏览器响应，不修改服务器任务。无模型推理或执行请求。
