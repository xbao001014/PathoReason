# Figure taxonomy and admission

Create an inventory row for each proposed panel: figure ID, panel label, narrative role, task/endpoint, prediction unit, required/optional, exact source paths and hashes, transformation, allowed claim, missing inputs, and admitted/refused/downgraded status. Availability is determined from inspected bytes, not filenames. A registered provider must enforce its own gate.

| Figure family | Required evidence | Optional evidence | Refuse or downgrade when |
| --- | --- | --- | --- |
| Cohort and study design | Deduplicated patient/slide mapping, inclusion/exclusion ledger, executed split and center assignments, endpoint definitions | Dates, acquisition/scanner strata, attrition reasons | Counts are only repeated fold observations: show partition counts, not unique cohort totals; never invent exclusion arrows |
| Method structure; training/inference | Executed code snapshot + hash, resolved configuration, task objective, tensor/head shapes, module switches | Checkpoint receipts and measured parameter counts | Manual brief or present-day code alone: retain an unverified handoff, no verified topology; training-only modules must not appear at inference |
| Quantitative comparison | Metric definition, original values, model identity, split/fold/seed, denominator, failure status | Case-level records, bootstrap or paired analysis receipt | Missing source values or incompatible protocols: refuse pooled comparison; show failed/missing cells explicitly |
| Ablation | Full/removal/control identities and executed interventions, matched folds/seeds/protocol, original outcomes | Paired patient differences, registered mechanism observations | Untested removal: refuse ablation; configuration comparison is not mechanistic proof |
| Classification | Observed labels, class order, predictions/probabilities, patient IDs, partition, positive class, threshold | Calibration protocol and uncertainty | Header-only predictions or aggregate AUC: refuse ROC, PR, confusion and calibration; aggregate metric plot remains possible |
| Regression | Target definition/unit, observed/predicted cases and missing mask for scatter; actual metric records for aggregate plots | Target transforms, residual diagnostics | Unknown inverse transform: no original-unit scatter; no conversion from R2/RMSE into invented predictions |
| Multilabel | Per-target observed masks, label order, patient predictions and positive counts | Macro/micro aggregation definitions | Missing values treated as negatives; mutually exclusive softmax assumption without evidence |
| Survival | Time origin/unit, event/censor encoding, follow-up, partition and risk/prediction definition | Fixed horizons, validated survival probabilities, covariates and baseline hazard | Risk alone does not support survival calibration; no pooled uncalibrated fold risks, invented KM/HR or treatment benefit |
| WSI / ROI / top patches | Real pixels and hash, slide/patient IDs, selection rule, patch IDs, coordinates, coordinate origin, pyramid level/downsample | Calibrated X/Y MPP, pathologist annotations | Feature tensors/coordinates alone: no tissue panels; absent MPP: omit physical scale bar; no cherry-picked top patches without ranking method |
| Attention / spatial | WSI evidence above + aligned patch-level attribution values, exact attribution method, checkpoint and input preprocessing hashes | Annotation overlap and uncertainty | Coordinates without pixels/attributions or mismatched IDs: refuse overlay; attention is not a lesion label |
| Clinical outcome / external validation | External cohort independence, locked model/threshold, endpoint/follow-up definition, denominators, estimates and uncertainty | Prospective protocol, subgroup fairness, decision analysis | Internal CV is not external validation or clinical utility; insufficient uncertainty prevents confirmatory claims |
| Multimodal evaluation | Patient-level modality joins, availability/missingness masks, modality-specific preprocessing and executed fusion config, matched unimodal controls | Missing-modality stress tests, modality attribution | Unpaired cohorts or unavailable modalities: refuse fusion advantage; no fabricated fusion topology |
| Foundation-model evaluation | Encoder/checkpoint/version, pretraining overlap audit, frozen/fine-tuned status, downstream protocol | Compute/latency receipts and external domains | Unknown pretraining overlap: label limitation; no unsupported generalization or zero-shot claims |

Downgrading changes both the figure and the caption: a protocol diagram cannot stand in for verified model architecture; an aggregate comparison cannot stand in for discrimination/calibration; development evidence cannot stand in for independent clinical validation.
